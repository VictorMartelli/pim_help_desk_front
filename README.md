## 📝 Sobre o Projeto

Este repositório contém o código-fonte do frontend para um sistema de Help Desk, desenvolvido como parte de um Projeto Integrado Multidisciplinar (PIM). A aplicação foi construída utilizando tecnologias modernas como React, TypeScript e Vite, com uma interface de usuário estilizada com TailwindCSS e componentes do Shadcn UI.

O sistema foi projetado para gerenciar chamados de suporte, oferecendo duas interfaces distintas de acordo com o perfil do usuário: **Solicitante** e **Atendente**.

---

## ✨ Funcionalidades

- **Autenticação de Usuários**: Sistema de login para acesso seguro à plataforma.
- **Perfis de Usuário**: Interfaces e funcionalidades específicas para Solicitantes e Atendentes.
- **Gerenciamento de Chamados**: Abertura, visualização e acompanhamento de tickets de suporte.
- **Interface Responsiva**: Layout adaptável para diferentes tamanhos de tela, construído com TailwindCSS.
- **Componentes Acessíveis**: Utilização de componentes da Radix UI para garantir uma melhor acessibilidade e experiência de usuário.

## 🚀 Como Executar o Projeto

Para executar o projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VictorMartelli/pim_help_desk_front.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pim_help_desk_front
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Execute a aplicação em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```

A aplicação estará disponível em `http://localhost:5173` (ou outra porta indicada no terminal).
